# Capturas de tela

Adicione as imagens nesta pasta, em formato PNG, com os nomes exatos abaixo. O README principal já aponta para esses arquivos.

| Arquivo | Conteúdo |
| --- | --- |
| `dashboard.png` | Painel consolidado |
| `rebalanceamento.png` | Simulação de rebalanceamento por aporte |
| `ir.png` | Relatório de imposto de renda do Brasil |
| `carteira.png` | Visão da carteira e dos ativos |

Use largura aproximada de **1280 px para desktop** ou **1080 px para celular**, mantendo o texto legível e a proporção da captura.

Prepare uma **conta de demonstração com carteira fictícia** antes de capturar as telas. Não deixe aparecer e-mail, nome real, valores reais ou dados de pagamento. Confira também menus, cabeçalhos e notificações antes de salvar cada imagem.

Revise cada PNG antes de substituí-lo no repositório público.
